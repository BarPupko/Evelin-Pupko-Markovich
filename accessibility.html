הצהרת נגישות

אנו מחויבים לספק חוויית גלישה נגישה לכלל המשתמשים, לרבות אנשים עם מוגבלויות, בהתאם לחוק שוויון זכויות לאנשים עם מוגבלות ותקנות הנגישות הישראליות.

♿ עומד בתקן WCAG 2.1 רמה AA
עדכון אחרון: פברואר 2026

1. מחויבותנו לנגישות

אוולין מרקוביץ' מאמינה שכל אדם זכאי לגישה שווה למידע ולשירותים דיגיטליים. אתר זה פותח ומתוחזק תוך שמירה על עקרונות הנגישות הדיגיטלית, בהתאם ל:

  • חוק שוויון זכויות לאנשים עם מוגבלות, תשנ"ח-1998
  • תקנות שוויון זכויות לאנשים עם מוגבלות (התאמות נגישות לשירות), תשע"ג-2013
  • תקן WCAG 2.1 רמה AA (Web Content Accessibility Guidelines)
  • ישראל 5568 – תקן הנגישות הישראלי לאתרי אינטרנט

3. מה עוד בתהליך שיפור

אנו ממשיכים לשפר את נגישות האתר באופן שוטף. פריטים הנמצאים בתהליך שיפור:
  • הוספת כיתוביות מלאות לסרטוני וידאו
  • בדיקת תאימות מלאה עם קוראי מסך (NVDA, JAWS, VoiceOver)
  • בדיקת נגישות אוטומטית חודשית באמצעות כלי Lighthouse ו-axe

4. טכנולוגיות נתמכות

האתר נבדק ותומך בשילובים הבאים:

  • דפדפן Chrome + Windows 11 (עם NVDA)
  • דפדפן Safari + macOS (עם VoiceOver)
  • דפדפן Firefox + Windows
  • מכשירים ניידים: iOS Safari, Android Chrome
